# КОТОСТРОФА-2026

Новогодний адвент для команды «Ваша Безопасность»: 17 оригинальных мемов, с 15 по 31 декабря 2026 года. Готовый статический сайт, без сборки и установки зависимостей.

## Как пользоваться

Откройте сайт по ссылке. До 15 декабря окошки закрыты. Каждый день в 00:00 по Уфе (Asia/Yekaterinburg, UTC+5) открывается новый мем; прошлые дни можно пересматривать. После 31 декабря все картинки остаются доступны, включая январь 2027 года и далее.

Нажмите на доступную дату. Картинка сразу помещается целиком в доступное окно без обрезки и прокрутки. Кнопка «+ Увеличить» показывает исходный размер; кнопка «− Уменьшить» возвращает показ целиком. Прокрутка появляется только после увеличения. Кнопка «Скачать картинку» сохраняет оригинальный PNG выбранного дня. Под картинкой — необязательная личная реакция. Её можно поменять. Крестик, Escape и нажатие на тёмный фон закрывают просмотр. Стрелки внизу переходят к соседним доступным дням.

На главной странице написано «17 окошек — с 15 по 31 декабря». Отдельный счётчик оформлен как лист отрывного календаря. Он показывает только полные оставшиеся сутки (24 часа) до 1 января 2027, 00:00 по Уфе: остаток не округляется вверх. Например, 28 октября 2026 в 12:00 по Уфе остаются 64 полных дня. Число обновляется автоматически без перезагрузки. Когда до праздника меньше суток, лист показывает 0 и подпись «Меньше суток!». Поздравление появляется только после наступления 2027 года. Закрытые даты подписаны «Пока секрет! Откроется … декабря».

Просмотр засчитывается только после успешной загрузки картинки. Повторный просмотр не прибавляет окошек. При сбое загрузки нажмите «Попробовать ещё раз».

## Как протестировать до запуска

Откройте `preview.html` рядом с `index.html` или добавьте `/preview.html` к адресу опубликованного сайта. Это отдельная тестовая страница с явной плашкой «Тестовый просмотр».

- По умолчанию тестовая дата — 31 декабря 2026, доступны все 17 окошек.
- Нажмите «Открыть 15 декабря», чтобы сразу увидеть окно с мемом, увеличением и реакциями.
- Для проверки доступности выберите 14, 15, 20, 31 декабря или 1 января 2027 в поле «Тестовая дата». Счётчик до Нового года также следует выбранной тестовой дате.
- «Сбросить тест» очищает только тестовые просмотры и реакции. Рабочая история сохраняется отдельно.
- Ссылка «Рабочий календарь» вернёт на `index.html`, где доступность определяется настоящей датой Уфы. Коллегам передавайте основную ссылку без `preview.html`.

Тестовая страница доступна любому, у кого есть её адрес; это удобный предпросмотр, а не защищённый административный раздел. На основной странице нет элементов управления тестовой датой.

## Как посмотреть файлы у себя

1. Распакуйте ZIP в отдельную папку.
2. Дважды нажмите `index.html`. Календарь работает без сборки и интернета: картинки и шрифты лежат рядом.
3. Работа сохранения при открытии файла с диска зависит от браузера. Для проверки постоянного прогресса используйте опубликованный сайт по HTTPS. Если сохранение заблокировано, календарь покажет предупреждение и продолжит работу в текущем посещении.

Дополнительный способ для тех, у кого уже установлен Python: откройте терминал в папке с `index.html`, выполните `python -m http.server 8000` и откройте `http://localhost:8000`. Для остановки нажмите Ctrl+C. Это необязательно для публикации.

## Публикация на GitHub Pages без программирования

1. Войдите в свой аккаунт GitHub и создайте новый репозиторий, например `kotostrofa-2026`. Для бесплатного обычного размещения выберите публичный репозиторий.
2. Распакуйте ZIP. Загружать нужно **содержимое** папки с `index.html`, а не сам архив и не внешнюю папку целиком.
3. В репозитории нажмите **Add file → Upload files**. Перетащите `index.html`, `styles.css`, `app.js`, `core.js`, `config.js`, `memes.js`, `dates.csv`, `.nojekyll`, папку `assets`, а также README, CHECKS и tests при желании. Сохраните загрузку кнопкой **Commit changes**. Структура папок внутри `assets` должна сохраниться.
4. Убедитесь, что `index.html` находится в корне репозитория, а рядом видна папка `assets`. Если `.nojekyll` не загрузился, создайте его через **Add file → Create new file**: имя `.nojekyll`, пустое содержимое, затем **Commit changes**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
6. В **Branch** выберите `main` (или фактическое имя вашей ветки), папку **/(root)** и нажмите **Save**.
7. Дождитесь публикации. В этом же разделе появится ссылка **Visit site**. Откройте её и передайте коллегам. Адрес обычно имеет вид `https://имя-аккаунта.github.io/kotostrofa-2026/`.
8. Для обновления замените нужные файлы в той же ветке. Сборка, API-ключи и подключение Sites не нужны.

Названия пунктов проверены по официальной инструкции GitHub 28.10.2026:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Проверка прогресса и реакций

В период календаря откройте доступный мем и дождитесь картинки. Закройте его: прогресс увеличится на один. Повторное открытие не изменит число. Выберите реакцию, закройте и обновите страницу. Прогресс и выбранная кнопка должны восстановиться. Реакцию можно изменить; это не меняет прогресс.

Хранение локальное: отдельные браузеры, устройства и домены имеют отдельную историю. При переносе с Sites на GitHub Pages старый прогресс автоматически не переносится. В приватном режиме браузер может удалять историю после закрытия. Очистка данных сайта сбросит и прогресс, и реакции. Никакие реакции и сведения о коллегах не отправляются на сервер; общей статистики нет.

## Что находится в комплекте

- `index.html` — страница календаря.
- `styles.css` — оформление и адаптация для телефона.
- `app.js` — модальное окно, реакции, навигация и сохранение.
- `preview.html`, `preview.js` — отдельный тестовый просмотр до запуска с независимой историей.
- `core.js` — расчёт даты по Уфе и вспомогательные функции.
- `config.js` — год, месяц, диапазон дней, часовой пояс, ключ хранения.
- `memes.js` — отдельное соответствие дат и локальных картинок, с текстовыми альтернативами.
- `dates.csv` — то же соответствие в читаемой таблице.
- `assets/memes/` — все 17 исходных PNG в оригинальном качестве, без перестановки.
- `assets/fonts/` — локальные шрифты и их лицензия.
- `assets/paw.svg`, `assets/pine.svg`, `assets/decor/` — декоративные элементы, узоры подарочной упаковки и отдельная фоновая иллюстрация новогоднего офиса.
- `.nojekyll` — прямое размещение статических файлов.
- `CHECKS.md` — результаты проверки.
- `tests/calendar.test.cjs` — необязательная проверка логики для разработчика (Node.js).

Все пути относительные: комплект работает в корне домена и в подпапке репозитория. Мемы не предзагружаются: запрашивается только картинка выбранного дня.

## Локальная проверка будущих дат (необязательно, для разработчика)

Не меняйте дату устройства и не редактируйте опубликованный интерфейс. Откройте локальную копию через HTTP. В консоли браузера задайте отдельную функцию времени:

```js
window.KotostrofaClock = () => new Date('2026-12-20T12:00:00+05:00');
```

В течение секунды доступны шесть дней. Другие контрольные даты: `2026-12-14T23:59:59+05:00`, `2026-12-15T00:00:00+05:00`, `2026-12-31T12:00:00+05:00`, `2027-01-01T12:00:00+05:00`. Возврат к реальному времени — перезагрузка. Переопределение существует только в открытой вкладке и не сохраняется в файлах.

Из папки комплекта можно выполнить `node tests/calendar.test.cjs`. Пользователям сайта и для размещения на GitHub Pages Node.js не нужен.

## Доступность файлов

Открытие по датам сохраняет сюрприз в интерфейсе. Картинки в статическом публичном репозитории технически доступны по прямым адресам до даты. Дополнительная защита содержимого не используется.
